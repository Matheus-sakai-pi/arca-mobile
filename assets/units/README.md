# Unit card illustrations

Generated with the built-in image_gen tool on 2026-10-14, then copied unchanged into assets/units. The original generated files remain in Codex's generated_images directory. These eight transparent PNGs supplement the existing bible-closed and prophet-thinking illustrations; all ten unit cards have distinct artwork.

## Shared Prompt

Use case: stylized-concept. Asset type: isolated transparent PNG illustration for a Bible learning mobile app unit card. Subject: [subject below]. Style: premium colorful 3D storybook cartoon, rounded sculpted shapes, warm golden soft lighting, crisp detailed edges, charming polished game illustration, matching a golden leather Bible with leaves. Composition: single cohesive centered vignette filling a square canvas, all objects fully visible, large readable silhouette for display at 120px; a few pale golden cloud-like forms behind the objects are okay but no rectangular background. Constraints: genuinely transparent background; no text, lettering, numbers, UI, border, watermark, logo or extra badges.
