# Mascote Arca

`idle.png` is the original transparent bitmap and is preserved unchanged. The typed `MascotState` registry now selects contextual assets:

- `thinking.png`: hand on chin, used for exercises.
- `reading.png`: open book, used for reading and comprehension.
- `celebrating.png`: joyful pose, used for correct answers and completion.
- `idle.png`: welcoming pose, also used to encourage after an incorrect answer.

All images use `contain` and genuine transparency. The new assets were generated separately with the built-in image tool, referencing the existing mascot and the supplied design direction. The reference sheet is not embedded or cropped into the app. Related states intentionally share poses; this is not a set of nine separate illustrations.
