# Journey assets

Nine real PNG assets generated with the built-in image tool. Transparent backgrounds are preserved. Human avatars and the existing mascot are not replaced.

Silver was generated first. Gold, current and locked were edited from that exact silver image, preserving the base design. Characters use the same rounded polished cartoon direction. The suggested lion failed generation; a turtle was used as the fifth character, as the requested set allowed adjustments.

Trail uses the full transparent characters; getAvatarSource uses the very same files in a circular view. Five human avatars remain available.
